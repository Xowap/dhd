# Motor Driver — DRV8833

The DRV8833 is a dual H-bridge motor driver used to control the motorized fader's
DC motor. Only one channel is used in this project.

## Key Specifications

| Parameter | Value |
|-----------|-------|
| Logic voltage | 3.3V compatible |
| Motor voltage (VM) | 2.7–10.8V |
| Continuous current per channel | 1.5A |
| Peak current | 2A |
| Control mode | PWM (Slow Decay) |

## Pin Connections

| DRV8833 Pin | Connects To | Purpose |
|-------------|-------------|---------|
| **VM** (VCC) | Pico VBUS (Pin 40, 5V) | Motor power supply |
| **GND** | Pico GND (Pin 38) | Common ground |
| **IN1** | GP14 (Pin 19) | PWM channel A (forward) |
| **IN2** | GP15 (Pin 20) | PWM channel B (reverse) |
| **OUT1** | Motor pin A | Power to motor |
| **OUT2** | Motor pin B | Power to motor |
| **EEP** (nSLEEP) | 3.3V (Pin 36) | Must be HIGH to enable driver |

## Control Truth Table

The firmware uses **Slow Decay** mode for precise PWM control:

| IN1 | IN2 | Function |
|-----|-----|----------|
| PWM | LOW | Forward at PWM duty |
| LOW | PWM | Reverse at PWM duty |
| LOW | LOW | Coast (motor free-spins) |
| HIGH | HIGH | Brake (motor shorts) |

## Firmware Implementation

The firmware configures GP14 and GP15 as PWM outputs on **PWM Slice 7**
(`PWM7_A` and `PWM7_B`). The PID controller outputs are mapped to (see
[`firmware/src/fader/interface.rs`](https://github.com/Xowap/dhd/blob/master/firmware/src/fader/interface.rs)):

- Positive effort → IN1 = duty, IN2 = HIGH (slow decay forward)
- Negative effort → IN1 = HIGH, IN2 = duty (slow decay reverse)
- Zero effort → both LOW (coast)

The slow decay mode (brake when OFF) provides better position holding and
smoother low-speed control compared to fast decay (coast when OFF).

## Unused Pins

The DRV8833 breakout has additional pins not used in this project:

- **IN3/IN4, OUT3/OUT4** — second H-bridge channel (unused)
- **nFAULT** — open-drain fault indicator (not monitored)
- **xISEN** — current sense resistor connection (tied to GND)
