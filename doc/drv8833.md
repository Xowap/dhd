# DRV8833 Motor Driver Reference for Raspberry Pi Pico 2

This document outlines the essential hardware specifications, pin quirks, and control logic required to interface a Raspberry Pi Pico 2 (3.3V logic) with the DRV8833 dual H-bridge motor driver.

## 1. Power & Logic Levels

The DRV8833 is natively compatible with the 3.3V logic of the Raspberry Pi Pico 2, but the motors must be powered independently. 

* **Motor Power Supply (VM):** Must be between **2.7V and 10.8V**. Do not power this from the Pico's 3.3V rail.
* **Logic Input Range:** The digital pins safely accept **-0.3V to 5.75V**. 
* **Logic High Threshold:** The driver registers a "High" signal at **2.0V** and above.

## 2. Current Limits

Ensure your motors do not exceed the chip's maximum current ratings to prevent thermal shutdowns.

| Configuration | Continuous Current (RMS) | Peak Current |
| :--- | :--- | :--- |
| **Standard (Two Motors)** | 1.5 A per motor  | 2.0 A per motor  |
| **Parallel (One Motor)** | 3.0 A total  | 4.0 A total  |

> **Note:** To run in parallel mode for a single larger motor, connect `AIN1` and `BIN1` together, `AIN2` and `BIN2` together, `AOUT1` and `BOUT1` together, and `AOUT2` and `BOUT2` together.

## 3. Crucial Pin Connections & Quirks

* **nSLEEP:** This pin dictates whether the driver is active or asleep. It has an internal pulldown resistor. You **must** drive this pin High (e.g., connect to a Pico 3.3V pin or drive a GPIO High) to enable the device. The chip requires up to **1 ms** to wake up and become operational.
* **xISEN (`AISEN`, `BISEN`):** These pins allow for hardware current chopping via external sense resistors. If you do not need hardware-level current limiting, connect both pins directly to Ground (GND).
* **nFAULT:** This pin drops to Logic Low if the driver encounters a fault, such as overcurrent or an overtemperature event. It is an open-drain output. To read it with the Pico 2, configure your input GPIO pin with an internal pull-up resistor.

## 4. Control Logic & PWM

The Pico 2 controls the motor states using the `xIN1` and `xIN2` pins (`AIN1`/`AIN2` for Motor A, `BIN1`/`BIN2` for Motor B). 

### Basic Movement Truth Table
| xIN1 | xIN2 | Motor State |
| :--- | :--- | :--- |
| 0 (Low) | 0 (Low) | Coast (Fast Decay)  |
| 1 (High) | 0 (Low) | Forward  |
| 0 (Low) | 1 (High) | Reverse  |
| 1 (High) | 1 (High) | Brake (Slow Decay)  |

### Speed Control (PWM)
To control motor speed, apply a PWM signal to the input pins. While the driver's internal current-control PWM operates at 50 kHz, standard Pico PWM frequencies will work for the input pins.

| xIN1 | xIN2 | PWM Function |
| :--- | :--- | :--- |
| **PWM** | 0 (Low) | Forward PWM (Fast Decay)  |
| 1 (High) | **PWM** | Forward PWM (Slow Decay)  |
| 0 (Low) | **PWM** | Reverse PWM (Fast Decay)  |
| **PWM** | 1 (High) | Reverse PWM (Slow Decay)  |
